# Практична робота №4 — ZenSpace

**Тема:** Динамічна взаємодія з користувачем: маніпуляції з DOM, обробка подій та використання можливостей BOM у JavaScript.

**Варіант:** А — продовження макета Zen Minimalism (wellness / meditation / productivity).

## Опис проєкту
ZenSpace — адаптивна вебсторінка у мінімалістичному стилі. На сторінці реалізовано форму відгуків, динамічне додавання коментарів, лічильник відгуків, лайки, перемикання теми та модальне вікно.

## Структура проєкту
- `index.html` — структура сторінки.
- `style.css` — оформлення та адаптивність.
- `app.js` — логіка DOM, подій та BOM.

## Як запустити
1. Завантажити або склонувати репозиторій.
2. Відкрити `index.html` у браузері.
3. Для локальної розробки можна скористатися розширенням Live Server у Visual Studio Code.

## Реалізовані технічні вимоги

1. **Підключення JavaScript:** скрипт винесено у файл `app.js` та підключено в `<head>` з атрибутом `defer`. Браузер завантажує файл паралельно з HTML і виконує його після побудови DOM.
2. **DOM:** для пошуку елементів використано `document.querySelector()` та `querySelectorAll()`. Текст оновлюється через `textContent`, елементи створюються через `document.createElement()`, класи змінюються через `classList.add()`, `remove()` та `toggle()`.
3. **Події:** обробники призначені через `addEventListener()`. Форма використовує `submit` і `event.preventDefault()`. Також застосовано `click`, `input`, `keydown`, `scroll` та `resize`.
4. **BOM:** використано `window.addEventListener()` для подій прокручування та зміни розміру вікна, а також властивості `window.innerWidth` і `window.scrollY`.

## Перевірка роботи
- Перемкнути світлу/темну тему кнопкою у верхній частині сторінки.
- Відкрити модальне вікно кнопкою «Дізнатись більше», закрити кнопкою, кліком поза вікном або клавішею `Escape`.
- Спробувати надіслати порожню форму або короткий текст — з’явиться повідомлення про помилку.
- Додати коректний відгук — він з’явиться на початку списку, а лічильник збільшиться.
- Натиснути сердечко — лічильник вподобань зміниться.
- Прокрутити сторінку — зверху змінюватиметься індикатор прогресу.

## Висновок
Під час виконання практичної роботи було створено інтерактивну вебсторінку ZenSpace із використанням JavaScript, DOM та BOM. Було опрацьовано способи вибірки HTML-елементів за допомогою сучасних CSS-селекторів, динамічного створення вузлів, зміни текстового вмісту та CSS-класів. Реалізовано обробку подій через `addEventListener()`, валідацію форми та скасування стандартної поведінки браузера методом `preventDefault()`. Також використано можливості BOM для відстеження прокручування сторінки та зміни розміру вікна. У результаті отримано адаптивний сайт із робочими інтерактивними елементами.

## Публікація на GitHub
1. Створити новий публічний репозиторій, наприклад `practical-work-4-zenspace`.
2. Завантажити до нього файли `index.html`, `style.css`, `app.js`, `README.md`.
3. У репозиторії відкрити **Settings → Pages**.
4. У полі **Build and deployment** обрати **Deploy from a branch**.
5. Вказати гілку `main` та папку `/ (root)`, натиснути **Save**.
6. Після публікації GitHub Pages покаже адресу працюючої сторінки.
